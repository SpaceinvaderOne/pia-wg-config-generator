If a config doesn't connect, or stops working later on, generate a new one — each config is tied to a single PIA server. [More details ▼]

Why a config stops working

Every config registers your device with one specific PIA server. PIA rebuild and rotate those servers regularly, and when yours is rebuilt its key changes and your registration is dropped — the tunnel then stops handshaking. Nothing is wrong with your account, your file, or this tool.

What to do:

  • Generate a new config and re-import it. Each one gets a fresh key on a different server, so there's no need to wait first.
  • On Unraid, replace the tunnel under Settings → VPN Manager.
  • Staying on the same region is fine. If one region keeps going stale, try another.

Occasionally a brand-new config won't connect. PIA will sometimes accept the registration and hand back a config that never works. Generating again is the fix.

Port forwarding isn't available on any US region. If you need it for a download client, choose a region outside the US — the dropdown marks this.

Once connected, PersistentKeepalive (25 seconds) holds the connection through brief network interruptions.
